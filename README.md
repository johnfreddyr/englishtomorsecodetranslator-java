# English to Morse Code Translator

A beginner-friendly Java program that converts English text into Morse code.

## Features

- Converts letters A-Z into Morse code
- Converts numbers 0-9 into Morse code
- Handles spaces between words
- Identifies unsupported special characters
- Uses Java arrays, loops, conditionals, strings, and Scanner input

## How It Works

The program takes text input from the user and processes each character individually. It searches for the corresponding Morse code using predefined arrays and prints the translated result.

## Concepts Used

- Java Arrays
- Parallel Arrays
- Nested for Loops
- Conditional Statements
- Character Manipulation
- String Manipulation
- Scanner for User Input
- Boolean Logic
- Problem Solving
